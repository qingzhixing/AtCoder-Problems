# D - Coefficient Stair

## 题目信息

题目链接：[atcoder.jp/contests/abc473/tasks/abc473_d](https://atcoder.jp/contests/abc473/tasks/abc473_d)

Clist Rating: 836

算法标签：暴力枚举 搜索 DFS 剪枝优化

## 题目大意

给定两个整数 **$N$** (**$1 \le N \le 10$**) 和 **$K$** (**$1 \le K \le 2 \times 10^5$**)。要求按字典序从小到大，输出所有满足 **$\sum_{i=1}^N i \times A_i = K$** 的非负整数序列 **$A$**。保证合法序列的总数不超过 **$3 \times 10^5$**。

## 关键观察

**等式约束带来降维** ：前 **$N-1$** 项一旦确定，当前的积累和 `sum` 也就固定了。根据等式，第 **$N$** 项必须满足 **$N \times A_N = K - \text{sum}$**。这意味着 **$A_N$** 被唯一确定，无需任何循环枚举。

## 算法思路

使用 DFS 按位从前往后填数。维护两个参数：当前正在填的索引 `idx`，以及已填入数字的乘积之和 `sum`。

对于第 `idx` 项（对应系数为 `idx + 1`）：

* **终止条件与剪枝** ：当进行到最后一项（`idx == N - 1`）时，直接计算剩余目标值 `delta = K - sum`。若 `delta % N == 0`，则该分支有效，令 **$A_N = \text{delta} / N$** 并输出整个序列；否则说明无法凑出精确的 **$K$**，直接丢弃（剪枝）。
* **常规搜索** ：对于非最后一项，从 **$0$** 开始枚举所有可能的数字，上限为当前剩余的容量除以当前系数，即 `(K - sum) / (idx + 1)`，并将更新后的 `sum` 传递给下一层。

## 复杂度

* **时间复杂度** ：**$O(N \cdot f(N,K))$**，其中 **$f(N,K)$** 为合法方案数。最底层有效搜索次数与解的数量同阶，约为 **$3 \times 10^6$** 次运算。
* **空间复杂度** ：**$O(N)$**，仅需一个长度为 **$N$** 的数组记录当前路径，以及 **$O(N)$** 的递归调用栈。

## 触发点（Takeaways）

* **字典序输出**，暗示使用 DFS 从小到大枚举。
* 需要**满足等式条件**时，可以尝试推导出在某些项确定时，剩下的项是否也能被唯一确定。
