# E: Subsegment Sum Finder

## 题目信息 (Problem Info)

* **难度评级**：Clist Rating `1129`
* **算法标签**：前缀和、容斥原理（差分拆分）、二维偏序、离散化、树状数组、二分查找

## 一句话题意 (One-Sentence Summary)

给定一个长度为 $N$ 且包含负数的整数数组 $A$，统计元素总和落在闭区间 $[L, R]$ 内的非空连续子数组个数（起止位置不同即视为不同子数组）。

## 关键观察/转化 (Key Observations/Transformations)

* **负数打破单调性**：由于 $A_i$ 可正可负，前缀和序列不具备单调性，无法使用双指针（滑动窗口）在线性时间内维护合法窗口。
* **差分消去双侧边界**：设 $f(X)$ 表示元素和 $\ge X$ 的非空连续子数组个数。在整数域下，$\text{sum} \in [L, R]$ 等价于 $\text{sum} \ge L$ 扣除 $\text{sum} \ge R + 1$，故原答案可拆解为 $\text{Ans} = f(L) - f(R + 1)$，把双边界限制简化为单侧前缀查询。
* **前缀和移项导出二维偏序**：令 $S_0 = 0, S_i = \sum_{k=1}^i A_k$，子数组 $A[j+1 \dots i]$ 的和满足 $S_i - S_j \ge X \iff S_j \le S_i - X$。将每个前缀状态看作二元组 $(k, S_k)$，固定右端点 $i$ 时，合法的左端点状态需同时满足**第一维下标 $0 \le j < i$** 与**第二维数值 $S_j \le S_i - X$**，形成标准二维偏序（二维数点）模型。
* **离散化压缩稀疏值域**：前缀和绝对值最高可达 $3 \times 10^{17}$，无法直接作为数组下标；但全局至多只有 $N + 1$ 个前缀和，通过排序去重将数值映射为 $[0, M)$ 的紧凑排名即可交由树状数组在 $\mathcal{O}(\log N)$ 内维护。

## 算法步骤 (Algorithm Steps)

* **构建前缀和序列**：初始化长度为 $N + 1$ 的前缀和数组 $S$，置基准值 $S_0 = 0$，依次累加得到 $S_1, S_2, \dots, S_N$。
* **前缀和离散化**：拷贝一份前缀和数组进行排序与去重得到有序坐标表 `coords`，并通过二分查找预处理出每个 $S_i$ 在 `coords` 中的排名下标 `ranks[i]`。
* **顺序扫描与树状数组计数**：在辅助函数 $f(X)$ 中按 $i = 0 \dots N$ 依次遍历（用遍历顺序自然消去 $j < i$ 维度）：每轮**先**在 `coords` 中二分定位满足 $\le S_i - X$ 的元素个数上界 `pos`，查询树状数组 `[0, pos)` 的前缀和累加至结果，**后**在树状数组的 `ranks[i]` 位置单点加 $1$。
* **作差输出答案**：分别计算 $f(L)$ 与 $f(R + 1)$，输出 $f(L) - f(R + 1)$（或在同一趟扫描中直接查询 $[S_i - R, S_i - L]$ 对应的离散区间和）。

## 复杂度 (Complexity)

* **时间复杂度**：$\mathcal{O}(N \log N)$。离散化排序耗时 $\mathcal{O}(N \log N)$；每次扫描遍历 $N + 1$ 个状态，单次二分查找与树状数组操作均为 $\mathcal{O}(\log N)$。
* **空间复杂度**：$\mathcal{O}(N)$。仅需线性空间存储前缀和数组、离散化坐标表、排名数组及树状数组。

## 触发信号 (Trigger Signals)

* 要求**统计元素和满足特定大小或区间关系的连续子数组个数**，且数组中**存在负数**（单调性失效，双指针不可用），数据规模在 $N \sim 10^5$ 级别。
* 计数条件带有**上下双边界 $L \le \text{val} \le R$**：优先考虑容斥拆分为两次单边界计数之差。
* 对前缀公式移项分离下标变量后，出现“位置 $j < i$ 且 $F(j) \le G(i)$”**的双维度独立不等式，且值域跨度巨大：立即套用**离散化 + 树状数组（或归并排序 + 双指针）降维求解。
