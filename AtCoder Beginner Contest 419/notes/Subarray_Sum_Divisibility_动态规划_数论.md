# H - Subarray Sum Divisibility

## 题目信息

Clist Rating：1283

算法标签：动态规划 (DP)、前缀和 (Prefix Sums)、同余/数论 (Modulo Math)、分组背包

## 题目大意

给定一个数组 $A$，每次操作只能给某个元素 $+1$，求最少的操作总次数，使得所有长度为 $L$ 的连续子数组元素之和均为 $M$ 的倍数。

## 关键观察

* **前缀和的周期性**：设区间前缀和为 $S$，若长度 $L$ 的区间和为 $M$ 的倍数，即 $S_i - S_{i-L} \equiv 0 \pmod M$，则必然有 $S_i \equiv S_{i-L} \pmod M$。
* **单点元素的周期性**：由前缀和推导回原数组，可得 $A_i \equiv A_{i+L} \pmod M$。这意味着，原数组在模 $M$ 意义下必须严格以 $L$ 为周期。
* **核心转化**：将原数组下标按模 $L$ 分成 $L$ 组，每组内部的所有元素最终对 $M$ 取模必须同余，且这 $L$ 个选定余数的总和必须是 $M$ 的倍数。问题转为了“分组求最小代价的同余背包问题”。

## 算法步骤

1. **分组**：将数组 $A$ 中的元素按下标 $i \bmod L$ 分为 $L$ 组。
2. **预处理代价**：对于每一组，计算将组内所有元素通过 $+1$ 操作统一变成模 $M$ 余数 $c$ ($0 \le c < M$) 的代价总和 `cost[c]`。
3. **初始化 DP**：定义一维数组 `dp[r]` 表示选定的前若干组余数总和模 $M$ 等于 `r` 时的最小代价。初始 `dp[0] = 0`，其余均为无穷大 `INF`。
4. **状态转移**：遍历这 $L$ 组，每一轮创建一个全新的 `next_dp` 初始化为 `INF`。对于 $0 \le r < M$（上一个状态）和 $0 \le c < M$（当前组选的余数），若 $dp[r] \neq INF$，执行转移：
   `next_dp[(r + c) % M] = min(next_dp[(r + c) % M], dp[r] + cost[c])`
   单组跑完后，令 `dp = next_dp`。
5. **输出结果**：所有 $L$ 组处理完毕后，`dp[0]` 即为总和是 $M$ 倍数时的最少操作次数。

## 复杂度

* **时间复杂度**：预处理单组代价的时间为 $O(\frac{N}{L} \cdot M)$，$L$ 组总计 $O(NM)$。DP 转移需要进行 $L$ 轮，每轮枚举状态 $O(M^2)$，转移代价为 $O(LM^2)$。总时间复杂度为 $O(NM + LM^2)$。
* **空间复杂度**：由于采用滚动数组更新，只需保留上一轮的 $dp$ 和当前轮的 $next\_dp$，空间复杂度降为 $O(M)$。

## 8. 触发信号

* 关键词：“所有长度为 $L$ 的区间和均为 $X$ 的倍数” $\to$ 核心反射条件：**序列模 $X$ 以 $L$ 为周期**。
* 题型结构：“多个独立分组各自做一个选择（花费代价），要求选择的属性总和满足某个模条件” $\to$ 核心反射模型：**按余数分类的滚动数组背包 DP**。
